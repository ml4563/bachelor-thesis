# 📰 Détection automatique de la violence de genre dans les médias avec IA

Ce dépôt contient mon **travail de Bachelor**, réalisé dans le cadre de mes études à la **HES-SO Valais-Wallis**.  

## 📖 Présentation  
Ce projet vise à développer une **application web** permettant de **détecter automatiquement la violence de genre** dans les médias francophones en **Suisse romande**.  

En combinant **intelligence artificielle (IA)** et **traitement du langage naturel (NLP)**, cet outil analyse la **couverture médiatique des violences sexistes** et en évalue la qualité selon des critères établis par l’institut **décadréE**.

- **Langages** : Python, Dart  
- **Backend** : Django REST  
- **Frontend** : Flutter  
- **Modèle NLP** : ChatGPT-4o, spaCy

# 📰 Automatic Detection of Gender-Based Violence in Media with AI  
### 🎓 *Bachelor’s Thesis - HES-SO Valais-Wallis*  

📌 🇬🇧 English | [🇫🇷 Français ⬆️](#-détection-automatique-de-la-violence-de-genre-dans-les-médias-avec-ia)  

This repository contains my **Bachelor’s thesis**, carried out as part of my studies at **HES-SO Valais-Wallis**.  

## 📖 Overview  
This project aims to develop a **web application** that **automatically detects gender-based violence** in French-language media in **Swiss Romandy**.  

By combining **artificial intelligence (AI)** and **natural language processing (NLP)**, this tool analyzes the **media coverage of gender-based violence** and evaluates its quality based on criteria established by the **décadréE institute**.  

📄 [**Access the full document**](https://folia.unifr.ch/global/documents/329887) *(available only in French)*  

## 🛠 Technologies Used  
- **Languages** : Python, Dart  
- **Backend** : Django REST  
- **Frontend** : Flutter  
- **NLP Model** : ChatGPT-4o, spaCy
